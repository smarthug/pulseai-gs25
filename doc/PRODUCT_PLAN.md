# PulseAI for GS25 - 기획 문서

> AI 기반 편의점 운영 자동화 솔루션

## 1. 제품 비전

**"편의점 점주의 AI 파트너"**

GS25 편의점에 설치되는 **미니 PC 하드웨어** + **OpenClaw AI 에이전트**:
- 🔧 장비 고장 예측 → 다운타임 제로
- 📦 스마트 자동 발주 → 재고 최적화
- 🤖 AI 알바 → 24시간 운영 지원

## 4. 핵심 기능

### 4.1 🔧 예측 유지보수

**OpenClaw가 로컬에서 수행:**
- POS 메트릭 실시간 수집 (CPU, Memory, Disk I/O)
- ECOD 다변량 이상탐지 (10초 주기)
- AutoARIMA 미래 예측 (1분 주기)
- 주변장치 상태 감시 (스캐너, 카드리더기 등)

**알림 시나리오:**
```
[OpenClaw 자동 감지]
- POS CPU 사용량 비정상 (ECOD score 0.85)
- 2시간 내 장애 예측 확률 78%

→ 카카오톡 알림:
"🚨 사장님, POS 점검이 필요해요!

CPU 사용량이 비정상적으로 높아요.
지금 재부팅하시면 예방할 수 있어요.

[지금 재부팅] [1시간 후 알림]"
```

### 4.2 📦 스마트 자동 발주

**데이터 수집:**
- POS 판매 데이터 연동
- 재고 데이터 연동
- 외부 API (날씨, 이벤트)

**자연어 인터페이스:**
```
점주: "이번 주 발주 뭐 해야해?"

OpenClaw: "📦 이번 주 발주 제안이에요!

[필수] 재고 부족 예상:
• 신라면 컵 12개 → 3일 후 소진
• 바나나우유 8개 → 2일 후 소진

[추천] 트렌드 반영:
• 제로콜라 (+30% 판매 증가)
• 컵얼음 (기온 상승 예보)

총 예상: 127,500원
[발주하기] [수정하기]"
```

### 4.3 🤖 AI 알바

**직원 지원:**
```
직원: "택배 접수 어떻게 해요?"

OpenClaw: "📦 택배 접수 방법 알려드릴게요!

1. POS에서 [택배] 터치
2. 보내는 분/받는 분 입력
3. 박스 크기 선택
4. 결제 후 운송장 출력
5. 택배함에 보관 (비번: 1234#)

오늘 마감은 오후 6시예요!"
```

**점주 비서:**
```
점주: "오늘 매출 어때?"

OpenClaw: "📊 오늘 매출 현황이에요!

💰 총 매출: 847,000원
📈 어제 대비: +12%
🏆 베스트: 삼각김밥 (82개)

시간대별로 보면 점심(12-13시)이
가장 좋았어요! 🎉"
```

## 5. OpenClaw Skills 구성

PulseAI Box에 설치되는 OpenClaw Skills:

```yaml
# openclaw.yaml
skills:
  - name: pulse-monitor
    description: POS/주변장치 모니터링 및 이상탐지
    triggers:
      - cron: "*/10 * * * * *"  # 10초마다
    
  - name: smart-order
    description: 발주 예측 및 제안
    triggers:
      - keyword: ["발주", "재고", "주문"]
      - cron: "0 9 * * *"  # 매일 9시
    
  - name: store-assistant
    description: 매장 운영 지원 (택배, 유통기한 등)
    triggers:
      - keyword: ["택배", "유통기한", "청소"]
    
  - name: sales-report
    description: 매출 분석 및 리포트
    triggers:
      - keyword: ["매출", "판매", "실적"]
      - cron: "0 22 * * *"  # 매일 22시 리포트

channels:
  - type: kakao
    target: store_owner
  - type: telegram
    target: admin
```
