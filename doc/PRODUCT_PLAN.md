# PulseAI for GS25 - 기획 문서

> AI 기반 편의점 운영 자동화 솔루션

## 1. 제품 비전

**"편의점 점주의 AI 파트너"**

GS25 편의점 운영에 필요한 모든 것을 AI가 자동화:
- 🔧 장비 고장 예측 → 다운타임 제로
- 📦 스마트 자동 발주 → 재고 최적화
- 🤖 AI 알바 → 24시간 운영 지원

---

## 2. 타겟 고객

### Primary: GS25 가맹점주
- 1인 운영 점주 (인건비 부담)
- 다점포 운영 점주 (관리 효율화)
- 신규 점주 (운영 노하우 부족)

### Secondary: GS리테일 본사
- 가맹점 지원 서비스
- 장비 유지보수 효율화
- 데이터 기반 인사이트

---

## 3. 핵심 기능

### 3.1 🔧 예측 유지보수 (PulseAI Core)

**현재 구현 완료:**
- POS 장비 실시간 모니터링
- ECOD 다변량 이상탐지
- AutoARIMA 미래 예측
- 주변장치 상태 감시 (스캐너, 카드리더기, 충전기 등)

**비즈니스 가치:**
| 문제 | 해결 | 효과 |
|------|------|------|
| POS 갑자기 고장 | 2시간 전 경고 | 영업 중단 방지 |
| 카드리더기 불량 | 실시간 감지 | 매출 손실 방지 |
| 야간 장비 이상 | 자동 알림 | 신속 대응 |

### 3.2 📦 스마트 자동 발주

**기능:**
- 판매 데이터 기반 수요 예측
- 유통기한 관리 자동화
- 시즌/이벤트/날씨 반영
- 자동 발주 제안 → 점주 승인 → 주문

**OpenClaw 연동:**
```
점주: "내일 비 온다는데 발주 어떻게 할까?"
AI: "비 오는 날 우산, 라면, 즉석밥 판매량이 평균 40% 증가합니다.
     현재 재고 기준 추가 발주 제안:
     - 신라면 5박스 → 8박스
     - 즉석밥 3박스 → 5박스
     발주 진행할까요?"
```

### 3.3 🤖 AI 편의점 알바

**역할:**
1. **고객 응대 지원**
   - 상품 위치 안내
   - 프로모션 안내
   - 택배/공과금 안내

2. **운영 업무 지원**
   - 유통기한 체크 알림
   - 청소/정리 체크리스트
   - 교대 인수인계

3. **점주 비서**
   - 매출 리포트
   - 이상 상황 알림
   - 본사 공지 요약

**OpenClaw 채널:**
- 📱 카카오톡 (점주용)
- 💬 텔레그램 (관리자용)
- 🖥️ 매장 태블릿 (직원용)

## 5. 사용자 시나리오

### 시나리오 1: 장비 이상 감지
```
[자동] 22:30 POS-1 CPU 사용량 급증 감지
[자동] ECOD 이상점수 0.85 (임계값 0.7 초과)
[자동] 2시간 내 장애 예측 확률 78%

→ 카카오톡 알림:
"🚨 POS 장비 점검 필요
현재 CPU 사용량이 비정상적입니다.
약 2시간 내 장애 가능성이 있어요.
지금 재부팅하시면 예방할 수 있습니다.
[지금 재부팅] [내일 점검 예약]"
```

### 시나리오 2: 자동 발주 제안
```
점주: "이번 주 발주 뭐 해야해?"

AI: "📦 이번 주 발주 제안드립니다!

[필수 발주] - 재고 부족 예상
• 신라면 컵 (현재 12개, 3일 후 소진)
• 바나나우유 (현재 8개, 2일 후 소진)
• 삼각김밥 (현재 15개, 내일 소진)

[추천 발주] - 트렌드 반영
• 제로콜라 (최근 판매량 +30%)
• 컵얼음 (기온 상승 예보)

총 예상 금액: 127,500원
[발주 진행] [수량 조정] [나중에]"
```

### 시나리오 3: AI 알바 - 직원 지원
```
직원: "손님이 택배 보내고 싶다는데 어떻게 해요?"

AI: "📦 택배 접수 방법 안내드릴게요!

1. POS에서 [택배] 버튼 터치
2. 보내는 분/받는 분 정보 입력
3. 박스 크기 선택 (소/중/대)
4. 결제 (현금/카드)
5. 운송장 출력 → 박스에 부착
6. 택배 보관함에 보관

💡 참고: 택배함 비밀번호는 1234#
오늘 마감 시간은 오후 6시입니다.

더 궁금한 거 있어요?"
```

## 6. 비즈니스 모델

### 가격 정책 (B2B SaaS)

| 플랜 | 월 가격 | 포함 기능 |
|------|---------|----------|
| **Basic** | 29,000원 | 장비 모니터링 + 알림 |
| **Standard** | 59,000원 | Basic + 자동발주 제안 |
| **Premium** | 99,000원 | Standard + AI 알바 + 매출분석 |
| **Enterprise** | 협의 | 다점포 관리 + 커스텀 |

### 수익 구조
1. **구독료** - 월 정기 결제
2. **설치비** - Edge Agent 설치 (1회)
3. **부가서비스** - 데이터 분석 리포트

### 예상 지표
- 타겟 시장: GS25 가맹점 ~17,000개
- 1차 목표: 100개 점포 (1%)
- 월 매출 목표: 5,900만원 (Standard 기준)
